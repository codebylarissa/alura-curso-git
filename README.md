# Curso de Git e GitHub da Alura 🚀

Repositório criado para colocar em prática os aprendizados do curso **Git e GitHub: compartilhando e colaborando em projetos** da Alura.

## 📌 Aprendizados do Curso

Durante as aulas, pratiquei o fluxo completo de trabalho com controle de versão, lidando com o dia a dia e a resolução de problemas no código:

- **Configuração e inicialização:** `git init`, `git config`
- **Ciclo de alterações:** `git status`, `git add`, `git commit`
- **Histórico e navegação:** `git log`
- **Conexão remota e sincronização:** `git remote`, `git push`, `git pull`
- **Autenticação segura:** Configuração de chave SSH no GitHub
- **Edição de commits:** `git commit --amend` (para ajustar a mensagem ou adicionar arquivos ao último commit)
- **Desfazendo e revertendo alterações:**
  - `git revert` (cria um novo commit desfazendo as alterações de um commit antigo com segurança)
  - `git reset` (remove commits do histórico ou volta o projeto a um estado anterior)
- **Resolução de Conflitos de Merge:** Identificação, edição manual dos arquivos com conflito e finalização da mesclagem no Git

## 🛠️ Ferramentas Utilizadas

- **Git**
- **GitHub**
- **VS Code** (Terminal, Editor e gerenciador de commits)
